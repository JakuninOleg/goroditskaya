# Городицкая и партнёры — сайт на Astro

Главная и 32 внутренние страницы. Статический HTML, локальные Prata и Manrope, собственные SVG-эмблемы и диаграммы. Общая система: лесной зелёный, светлая бумага, шалфей, жёлтый акцент и солнечный кабинет.

## Команды

- npm ci
- npm run dev
- npm run build
- npm run preview
- npm run check:build — главная, ресурсы и формы.
- npm run check:pages — все HTML, ссылки, якоря, метаданные, JSON-LD, sitemap и достижимость.
- npm run check:pages -- --url=http://127.0.0.1:4322 — дополнительно HTTP-ответы всех страниц и настоящий 404.
- node --test scripts/test-ru-phone.mjs scripts/test-iceberg-leaders.mjs
- node scripts/build-brand-assets.mjs — логотипы, favicon, touch icon и изображение для публикации ссылки.

## Структура

- src/data/services.ts — 13 услуг: предложение, ситуации, состав, результат, этапы, входные данные, FAQ и связанные страницы.
- src/pages/uslugi/[slug].astro — статические страницы услуг по адресам из данных.
- /uslugi/ — каталог четырёх направлений из материалов Натальи: бухгалтерский учёт и отчётность, финансовое управление, налоговая безопасность, юридическая помощь.
- /o-natale/ — профиль и личная роль Натальи.
- /kejsy/ и /kejsy/niokr-62-mln/ — подтверждённый кейс без выдуманных клиентов и результатов.
- /kontakty/ — рабочие контакты и заявка с переносом выбранной услуги в поле задачи.
- /materialy/ — три Excel-формы и запрос комплекта через контактную форму. Публичной прямой загрузки нет.

Маршруты первого SEO-плана сохранены. Дополнения Натальи по CFO, налогам и юридической помощи получили отдельные страницы. ERP/КА/КОРП/Бит.Финанс не размножены в отдельные посадочные страницы.

## Поиск и публикация

src/data/seo.ts задаёт основной адрес https://gorodickaya.ru и согласованный режим индексирования. Индексация пока выключена: все HTML содержат noindex, nofollow, а Timeweb дополнительно отдаёт X-Robots-Tag. robots.txt разрешает обход, чтобы робот мог прочитать noindex; ссылка на sitemap появится в robots.txt только после включения индексации. Sitemap и robots формируются при сборке; canonical указывает на конкретную страницу основного домена. 404 всегда закрыт от индексации и исключён из sitemap. JSON-LD услуг и хлебных крошек соответствует видимому содержанию.

Перед релизом проверять фактическое значение searchIndexingEnabled; не менять его без согласования режима запуска. Идентификатор Sites сохранён в .openai/hosting.json. Одна версия исходников публикуется в Sites и GitHub/Vercel. Сборка находится в dist.

Промпты, карта страниц и результаты проверок: research/internal-pages-2026-10-19/.

## Оптимизация медиа

AVIF-варианты созданы из утверждённых WebP. На телефонах используется тот же исходник hero-neck-v4, что и на десктопе: AVIF 2048×768, 89 860 байт; WebP сохранён для совместимости. Отдельный сгенерированный мобильный портрет больше не подключён. Кадрирование выполняется через object-fit: cover без растяжения; под кнопкой зарезервировано место, чтобы она не закрывала руки и блокнот. Пересборка производных: `python -X utf8 scripts/optimize-images.py` (Pillow с AVIF). Рабочий сайт Python не использует.

Критические стили встроены при сборке, два основных кириллических шрифта и соответствующий экрану hero загружаются приоритетно. Сайт остаётся статическим; отправку обслуживает отдельный серверный маршрут. Без JavaScript доступны прямые контакты.
