# Наталья Городицкая · сайт на Astro

Зелёный сайт на Astro. Редакционная композиция обновлена 17 октября 2026 года по референсу владельца.

## Запуск

```sh
npm ci
npm run dev
npm run build
npm run preview
```

## Содержание и стили

- Главная: src/pages/index.astro.
- Тексты, вопросы и продукты: src/data/site.ts.
- Палитра, отступы и адаптация: src/styles/global.css.
- Редакционная композиция и адаптация референса: src/styles/editorial.css.
- Авторские многослойные SVG-иллюстрации: src/components/ArtIcon.astro. Служебные значки: src/components/Icon.astro.
- Вкладки, диалоги, меню и подготовка письма: src/scripts/main.ts.
- Пример финансовой отчётности: src/components/FinancialReport.astro.
- Основные цвета: #153D3A, #F5F2E9, #E8C74F, #E6ECE5.

## Возможности

Девять вопросов собственника переключают пояснения у айсберга. Три услуги раскрываются в диалоге; налоговое направление содержит пять конкретных ситуаций. Вкладки показывают примеры финансовых инструментов, форматы работы и отрасли опыта. Поддерживаются клавиатурная навигация, Escape, возврат фокуса из диалогов, reduced motion и мобильное меню. Годовой пример отчётности содержит условные помесячные данные: выручка 48,2 млн ₽, прибыль 7,6 млн ₽, рентабельность 15,8%.

## Обращения

Сервис отправки писем/CRM не подключён. Форма проверяет обязательные поля и готовит текст письма в браузере. Посетитель самостоятельно открывает его в почтовой программе либо копирует и отправляет. Сайт не сохраняет данные и не сообщает об успешной отправке. Прямая связь: gorodickaya@yandex.ru, +7 (918) 859-38-00.

## Комплект форм

public/downloads/financial-templates.xlsx содержит три базовых шаблона с инструкциями и формулами: ДДС на 13 недель, прибыль по проектам, план-факт расходов. Жёлтые ячейки предназначены для ввода. Файл доступен без регистрации. Это стартовые формы, которые необходимо адаптировать к компании.

## Материалы

Портрет natalia-editorial.webp подготовлен image_gen из выбранного пользователем портрета в макете. Панорамная сцена natalia-office.webp и её уменьшенная версия сделаны встроенным image_gen с сохранением выбранного образа. Это адаптации концептуального референса, а не новая документальная фотосъёмка. Айсберг — сгенерированная иллюстрация. Иконки отрисованы в SVG. Исходные макеты и промпты хранятся вне публичной сборки, в research.

В кейсе Технорэд использованы данные Натальи, переданные пользователем и разрешённые им к публикации. Срезы за 6 и 9 месяцев имеют разную длительность. Год и вид прибыли не установлены; соответствующая подпись сохранена. Объём затрат на НИОКР не представлен как поступление денег или независимая оценка стоимости компании.

## Статус публикации

Сохранены адрес сайта и запрет индексации черновой версии. Удаление noindex и изменение robots.txt выполняются после утверждения содержания. Сборка статическая, экспортируются только dist и конфигурация хостинга; research и исходные резюме в неё не входят.
