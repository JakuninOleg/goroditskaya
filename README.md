# Городицкая и партнёры — сайт на Astro

Главная и 32 внутренние страницы. Статический HTML, локальные Prata и Manrope, собственные SVG-эмблемы и диаграммы. Общая система: лесной зелёный, светлая бумага, шалфей, жёлтый акцент и солнечный кабинет.

## Команды

- npm ci
- npm run dev
- npm run build
- npm run preview
- npm run check:build — главная, ресурсы и формы.
- npm run check:pages — все HTML, ссылки, якоря, метаданные, JSON-LD, sitemap и достижимость.
- npm run check:pages -- --url=http://127.0.0.1:4322 — дополнительно HTTP-ответы всех страниц и настоящий 404.
- node --test scripts/test-ru-phone.mjs scripts/test-iceberg-leaders.mjs
- node scripts/build-brand-assets.mjs — логотипы, favicon, touch icon и изображение для публикации ссылки.

## Структура

- src/data/services.ts — 13 услуг: предложение, ситуации, состав, результат, этапы, входные данные, FAQ и связанные страницы.
- src/pages/uslugi/[slug].astro — статические страницы услуг по адресам из данных.
- /uslugi/ — каталог четырёх направлений из материалов Натальи: бухгалтерский учёт и отчётность, финансовое управление, налоговая безопасность, юридическая помощь.
- /o-natale/ — профиль и личная роль Натальи.
- /kejsy/ и /kejsy/niokr-62-mln/ — подтверждённый кейс без выдуманных клиентов и результатов.
- /kontakty/ — рабочие контакты и заявка с переносом выбранной услуги в поле задачи.
- /materialy/ — три Excel-формы и запрос комплекта через контактную форму. Публичной прямой загрузки нет.

Маршруты первого SEO-плана сохранены. Дополнения Натальи по CFO, налогам и юридической помощи получили отдельные страницы. ERP/КА/КОРП/Бит.Финанс не размножены в отдельные посадочные страницы.

## Факты

Наталья работает в финансах с 2003 года и руководит финансовой частью проектов команды «Городицкая и партнёры». Учётные, налоговые и юридические задачи ведут профильные специалисты. Управление командой более 50 специалистов описано как прошлый опыт. Юридические и технические работы выполняются профильными исполнителями. Господдержка отдельно не предлагается.

Кейс: 62 млн ₽ затрат отнесены к НИОКР с положительным результатом в виде технологии и патентов. Не используются неподтверждённые периоды, сравнения прибыли или название компании. Сумма не представляется денежным поступлением.

Фото и контакты разрешены владельцем к публикации. Происхождение изображений учтено в research. Тексты основаны на материалах Натальи и карте семантики; ссылки на правовые источники есть на соответствующих страницах.

## Формы

Серверная отправка и автоматическая выдача отложены владельцем. После валидации открывается подготовленный mailto; подтверждение успешной отправки не имитируется. Форма обращения требует один контакт на выбор: телефон или почту, и согласие. Форма запроса Excel-комплекта требует почту и телефон. Получатель всех обращений — Gorodickaya@yandex.ru. В клиентском интерфейсе нет описаний внутренней реализации.

## Поиск и публикация

src/data/seo.ts задаёт основной адрес и согласованный режим индексирования. Sitemap и robots формируются при сборке; canonical указывает на конкретную страницу основного домена. 404 всегда закрыт от индексации и исключён из sitemap. JSON-LD услуг и хлебных крошек соответствует видимому содержанию.

Перед релизом проверять фактическое значение searchIndexingEnabled; не менять его без согласования режима запуска. Идентификатор Sites сохранён в .openai/hosting.json. Одна версия исходников публикуется в Sites и GitHub/Vercel. Сборка находится в dist.

Промпты, карта страниц и результаты проверок: research/internal-pages-2026-10-19/.
## Кейсы и сравнение стоимости

`src/data/cases.ts` содержит девять обезличенных кейсов и их связь со всеми 13 услугами. Восемь новых разборов основаны на описанном в резюме опыте Натальи; исходный кейс НИОКР сохранён. Несколько разборов относятся к одному месту работы: они не выдаются за разных клиентов. Карта первичных фактов хранится вне публичного проекта. Юридическая часть договорного контура отделена от финансовой роли Натальи.

`ServicePricing.astro` используется на главной и странице независимого финансового директора. Сравнение со штатным сотрудником удалено. Стоимость услуг — от 5 000 ₽; объём и итоговая стоимость согласуются до начала.

## Оптимизация медиа

AVIF-варианты созданы из утверждённых WebP без изменения композиции. Мобильный hero уменьшен с 1 220 772 до 72 210 байт в исходном размере 850×1851. Адаптивные варианты задаются через picture/srcset; WebP сохранён для совместимости. Пересборка производных: `python -X utf8 scripts/optimize-images.py` (Pillow с AVIF). Рабочий сайт Python не использует.

Критические стили встроены при сборке, два основных кириллических шрифта и соответствующий экрану hero загружаются приоритетно. Серверная доставка форм по-прежнему отложена; JS сохраняет согласованный сценарий mailto, без ложного подтверждения отправки. Без JavaScript доступны прямые контакты.
