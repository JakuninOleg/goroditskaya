# Наталья Городицкая · сайт на Astro

Первая версия по предоставленному макету. Молочный фон, тёмно-синий и лайм; более просторная вертикальная композиция.

## Запуск

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Основные тексты и контакты: `src/data/site.ts`. Главная: `src/pages/index.astro`. Стили: `src/styles/global.css`. Портрет: `public/images/natalia.png`.

## Контакты

Телефон, email и оригинальное фото взяты из резюме, предоставленного пользователем. Контактное окно готовит текст письма на странице; посетитель копирует его или самостоятельно открывает ссылку для почтовой программы. Сайт ничего не отправляет и не сохраняет.

## Перед публичным запуском

Подтвердить актуальность контактов, фото, текста и фактов опыта. Настроить домен, абсолютные метаданные, canonical, OG-изображение и sitemap. Убрать `noindex, nofollow` и запрет обхода в robots.txt только после утверждения содержания. При необходимости заменить подготовку письма реальной доставкой в CRM/email с обработкой ошибок и политикой персональных данных.

В первой версии намеренно отсутствуют неподтверждённые отзывы, цены и гарантии финансирования. Это работающая статическая версия для просмотра и дальнейшей редакции.
