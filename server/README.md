# Доставка заявок

`leads.mjs` — отдельный обработчик для сайта «Городицкая и партнёры». `route.js` подключает его к уже работающему Next.js приложению Timeweb 262097, путь `src/app/api/natalia-lead/`. Обе версии файлов должны совпадать. Новое платное приложение не создаётся. Существующие обработчики портфолио не меняются.

Получатель почты фиксирован: `Gorodickaya@yandex.ru`. Для доставки используется уже подключённый Resend и подтверждённый отправитель. Для Telegram нужны отдельный токен бота и chat_id личного чата Натальи. Наталья должна сама нажать «Старт» у бота. Переменные перечислены в `environment.example`; секреты хранятся только в серверном окружении.

Проверки: допустимый Origin, ограничение размера, контакты, отдельное согласие актуальной редакции, ловушка для ботов, пять попыток в минуту на IP. CORS не является аутентификацией: небраузерный клиент может подделать Origin. При устойчивом спаме потребуется дополнительная проверка.

Сервер добавляет номер заявки и время по Москве. Почта и Telegram вызываются независимо; подтверждение показывается только после принятия сообщения хотя бы одним настроенным каналом. Отказ одного канала не отменяет другой. В логах только номер заявки, канал и статус, без контактов и текста. Новая заявка не отправляется заново при двойном нажатии; для почты также используется ключ идемпотентности Resend.

Повторы хранятся в памяти 15 минут, поэтому отдельного постоянного журнала заявок и фоновой очереди здесь нет. После перезапуска защита от дубля Telegram не сохраняется. При отказе обоих каналов возвращается ошибка; форма сохраняет ввод и позволяет повторить отправку. Успех API означает принятие провайдером, а не гарантированное попадание во «Входящие».

`node --test server/leads.test.mjs` проверяет реальный HTTP-сценарий с локальными приёмниками провайдеров; внешние письма и Telegram-сообщения при этом не отправляются.

Перед включением на сайте: развернуть маршрут на существующем сервере, настроить оба канала и проверить получение контрольной заявки на почте и в личном чате Натальи. Обновление юридических документов отражает фактически подключённые сервисы; уведомления Роскомнадзору и организационные обязанности оператора не выполняются изменением текста страницы.
